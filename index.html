JavaScript - Proyecto (Pokedex).

A partir de los archivos HTML y CSS proporcionados, desarrolle la programación necesaria para implementar una Pokédex que permita consultar Pokémony visualizar su información (Nombre, número de Pokémon y Tipo). Para obtener los datos, deberá utilizar JavaScript y la API pública PokéAPI.

URL de la API: https://pokeapi.co/api/v2/pokemon?limit=151

¿Qué es una API?

Una API Interfaz de Programación y Aplicaciones es un conjunto de reglas y herramientass que permite que diferentes aplicaciones o sistemas se comuniquen entre si e intercambien información. Funciona como un intermediario que recibe solicitudes, las comunica al sistema correspondiente y devuelve una respues con los datos solicitados.

Las API permiten, por ejemplo, consultar el clima desde una aplicación, obtener información de un servicio externo o integrar funciones de una plataforma en otra, sin necesidad de desarrollar todas esas funcionalidades desde cero.

Requisitos del proyecto.

  • Permitir buscar un Pokémon y realizar la consulta correspondiente.

  • Obtener los datos de los Pokémon desde la PokéAPI.

  • Mostrar el nombre, número de identificación, imagen y tipos correspondientes al Pokémon consultado.

  • Actualizar la información presentada cada vez que se realice una nueva búsqueda.

La programación deberá realizarse e un archivo JavaScript independiente, vinculado correctamente con el documento HTML proporcionado.



Ayuda:

Renderización de datos con innerHTML.

Una vez obtenido la información de un Pokémon desde la API, será necesario mostrarla en el documento HTML. Para realizar esta tarea, JavaScript permite utilizar la propiedad innerHTML, que permite modificar el contenido HTML de un elemento.

Mediante este propiedad, es posible incorporar textos, imágenes y otros elementos HTML utlizando los datos recibidos desde la API.


Ejemplo: 
     // Seleccionar el elemmento HTML
    const contenedor = document.getElementById("pokemon")

    // Mostrar los datos del objeto.
    contenedor.innerHTML = `
    <h2>${datos.name}</h2>
    <img src="${datossprites.front_default}">
    `;

Explicación:

  • document.getElementById("pokemon"): Permite seleccionar el elemento HTML que tiene el identificador pokemon.

  • datos.name: accede al nombre almacenado en el objeto.

  • datos.sprites.front_default: Accede a la dirección de la imagen.

Las comillas invertidas o (backtick) permiten escribir HTML en varias líneas e insertar valores mediante ${}.
